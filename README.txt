================================================================================
  ccode  --  Dev-C++ 里的 AI 代码助手
================================================================================

在 Dev-C++ 5.11 里按一个热键，用中文描述需求，AI 生成 C 代码，看一眼预览
再决定插不插入。后端走 DeepSeek API，纯 Python 标准库实现，无需 pip 安装
任何依赖，API key 只存在你自己机器上。

之所以做这个东西：Dev-C++ 5.11 是很多学校 C 语言课指定的 IDE，但它 2015 年
就停止维护了，没有插件接口、没有 AI 辅助、界面语言文件还有点毛病。这个项目
用"外部程序 + 模拟按键"的方式，在不改动 Dev-C++ 本体的前提下补上这些能力。


--------------------------------------------------------------------------------
  1. 它能做什么
--------------------------------------------------------------------------------

  * 生成代码     描述需求 -> 生成完整可编译的 C 代码 -> 预览 -> 一键插入编辑器
  * 续写补全     选中已写的几行 -> 生成接下来的部分 -> 预览 -> 插入
  * 改写代码     粘贴一段代码 + 写要求（如"改成用递归"）-> 生成改写结果
  * 本地片段库   18 条 C 常用片段灌进 Dev-C++ 自带的代码插入功能，不联网、
                 不消耗 API 额度
  * 顺手修的 bug 把 Dev-C++ 的 GBK 语言文件转成 UTF-8，解决界面满屏方块乱码

  "预览"这一步就是自己决定是否保留：预览窗里 Ctrl+Enter 插入，Esc 丢弃。


--------------------------------------------------------------------------------
  2. 运行环境
--------------------------------------------------------------------------------

  * Windows（用到 Win32 剪贴板与模拟按键 API）
  * Dev-C++ 5.11（Orwell/Bloodshed 版）
  * Python 3.8 以上，需要带 tkinter（Windows 官方安装包自带）
  * 一个 DeepSeek API key： https://platform.deepseek.com
    充值 10 元可用很久；也可改用任何 OpenAI 兼容接口（改 base_url 即可）


--------------------------------------------------------------------------------
  3. 安装
--------------------------------------------------------------------------------

  第 1 步  放文件
     把 ccode.py、ccode.cmd、ccode-gen.cmd、ccode-complete.cmd 放到一个
     固定目录，例如：
         C:\tools\ccode\

  第 2 步  填 API key
     双击 ccode.cmd
     -> 弹出"还没有配置 API key"-> 点"是"
     -> 粘贴 key -> 保存

     也可以命令行执行：
         python ccode.py config

     key 会写进同目录的 ccode.json。这个文件已经写进 .gitignore，
     不会被误提交到仓库。

  第 3 步  启动窗口级热键（推荐）
     ccode-hotkey.cmd

     它是个后台常驻的小程序，装一个低级键盘钩子，只在 Dev-C++ 是前台窗口时
     才拦截 Ctrl+I / Ctrl+Alt+K；其他程序里按键原样通过，斜体、Copilot 等
     功能都不受影响。

     想开机自启：Win+R 输入 shell:startup，把 ccode-hotkey.cmd 的快捷方式
     丢进去即可。

     想换热键：改 ccode-hotkey.py 顶部的 VK_I / VK_K，以及 _handler 里的
     修饰键判断。

  第 4 步  Dev-C++ 工具菜单（这版 Dev-C++ 不可用）
     实测 工具(T) -> 配置工具(T) 弹出来的对话框里只有一个空列表框和两个分组框，
     没有任何添加 / 编辑 / 确定按钮，无法往工具菜单里加外部程序；
     devcpp.ini 的 [ExternalPrograms] 段也只有 Dummy=0，真实数据是内部序列化格式。
     所以别指望菜单项，用第 3 步的热键。

  第 5 步  灌入本地片段库（可选）
     python add_snippets.py

     修改前请先备份：
         copy "%APPDATA%\Dev-Cpp\codeinsertion.ini" "%APPDATA%\Dev-Cpp\
         codeinsertion.ini.bak"
     脚本已内置防重复（检测到标记就跳过）。


--------------------------------------------------------------------------------
  4. 用法
--------------------------------------------------------------------------------

  4.1  窗口级热键（最顺手）

     Ctrl+I       在输入框写需求，例如：
                     写个学生成绩管理系统，用结构体数组，能增删改查
                  -> Ctrl+Enter 生成
                  -> 预览窗里 Ctrl+Enter 插入到 Dev-C++ / Esc 丢弃

     Ctrl+Alt+K   先在 Dev-C++ 里选中你已写好的代码，再按热键
                  -> 输入框里已自动带上选中内容（不需要再粘贴）
                  -> 可以补充要求，也可以直接回车
                  -> 预览 -> 插入

     这两个键只在 Dev-C++ 是前台窗口时生效；别的程序里 Ctrl+I 照常是斜体。

  4.2  关于 Dev-C++ 工具菜单
     这版 Dev-C++ 的配置工具对话框没有添加入口，装不进去（见第 4 步说明）。
     补全模式会先模拟 Ctrl+C 读取你在编辑器里选中的内容。

  4.3  命令行

     python ccode.py gen --prompt "写个冒泡排序"
     python ccode.py complete --file a.c --wordxy 12,5
     python ccode.py config         编辑配置
     python ccode.py selftest       自检：key、剪贴板、能否找到 Dev-C++ 窗口
     python ccode.py gen --mock     不联网，用假代码验证界面与插入流程

     调试窗口定位问题很方便的写法：
     python ccode.py selftest


--------------------------------------------------------------------------------
  5. 配置项（ccode.json）
--------------------------------------------------------------------------------

  api_key         DeepSeek 的 key，sk- 开头
  base_url        接口地址，默认 https://api.deepseek.com/v1
                  换其他 OpenAI 兼容服务时改这里即可
  model           模型名，默认 deepseek-chat
  temperature     创造性，默认 0.2（写代码建议低一点）
  max_tokens      单次生成上限，默认 2048
  timeout         请求超时秒数，默认 120
  devcpp_exe      Dev-C++ 主程序路径，用于把焦点切回去粘贴
  context_chars   补全时最多带多少字符的上文，默认 4000

  从仓库 clone 下来的人：把 ccode.example.json 复制成 ccode.json 再填 key 即可。


--------------------------------------------------------------------------------
  6. 常见问题
--------------------------------------------------------------------------------

  Q: 按热键没反应？
  A: 快捷方式必须放在开始菜单或桌面，Windows 才会注册它上面的热键。
     重跑 make_hotkeys.ps1 即可重建。

  Q: 预览窗点"插入"，代码没进编辑器？
  A: 先跑 python ccode.py selftest，看"Dev-C++"那行是否找到窗口。
     找不到就确认 devcpp_exe 配置的路径对不对、Dev-C++ 是否已经打开。

  Q: 提示 401 / 402？
  A: 401 是 key 无效，重新跑 ccode.py config；
     402 是 DeepSeek 账户余额不足，去官网充值。

  Q: 生成的中文注释在 Dev-C++ 里是乱码？
  A: 那是编辑器的源码编码问题，不是本工具的。Dev-C++ 里用
     编辑(E) -> 文件属性 把编码设成 UTF-8。

  Q: Dev-C++ 界面全是方块乱码？
  A: 语言文件 <Dev-C++ 安装目录>\Lang\Chinese.lng 是 GBK 存的，而 Dev-C++ 5.11 按
     UTF-8 读。用 Python 转一下即可：
         data = open(路径, 'rb').read().decode('gbk')
         open(路径, 'wb').write(data.encode('utf-8'))
     记得先备份原文件。


--------------------------------------------------------------------------------
  7. 能力边界（先说清楚）
--------------------------------------------------------------------------------

  * 没有行内灰字补全（ghost text）。Dev-C++ 5.11 没有插件 API，无法在编辑器
    里画灰色预览文字。所以补全是"按键触发 -> 预览窗 -> 插入"。
  * 没有内联 diff。看不到 VS Code 那种红绿对比，只能看预览窗后决定。
  * 拿不到"选中文本"。Dev-C++ 外部工具只暴露文件名、路径、光标行列等宏，
    所以补全模式是用模拟 Ctrl+C 读取选中内容实现的。
  * 生成质量取决于模型，作业代码仍要自己看懂、自己跑通。


--------------------------------------------------------------------------------
  8. 卸载
--------------------------------------------------------------------------------

  1) 删掉开始菜单 Programs 下的 ccode-gen.lnk 和 ccode-complete.lnk
  2) 删掉放代码的目录
  3) 还原 Dev-C++ 片段库（如果灌过）：
         copy "%APPDATA%\Dev-Cpp\codeinsertion.ini.bak" "%APPDATA%\Dev-Cpp\
         codeinsertion.ini"


--------------------------------------------------------------------------------
  9. 文件说明
--------------------------------------------------------------------------------

  ccode.py            主程序：API 调用、输入窗、预览窗、剪贴板、模拟按键
  ccode-hotkey.py     窗口级热键守卫：只在 Dev-C++ 前台时拦截 Ctrl+I / Ctrl+Alt+K
  ccode-hotkey.cmd    启动上面那个守卫（放进启动文件夹即可开机自启）
  ccode.cmd           通用启动器（用 pythonw 跑，不弹黑框）
  ccode-gen.cmd       备用"生成"入口（可直接双击）
  ccode-complete.cmd  备用"补全"入口
  make_hotkeys.ps1    旧的全局热键方式，已不推荐
  add_snippets.py     往 Dev-C++ 的 codeinsertion.ini 里灌 C 片段
  ccode.example.json  配置模板（不含密钥）

  移植注意：三个 .cmd 依赖 PATH 里的 pythonw（找不到则退回 python）；
  make_hotkeys.ps1 用脚本自身所在目录定位 ccode.cmd；
  add_snippets.py 通过 %APPDATA% 定位 Dev-C++ 的配置文件。
  三处都不需要改代码，clone 到任何 Windows 机器上即可用。
